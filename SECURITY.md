# Security Policy

## Reporting a Vulnerability

Please report security issues **privately** — do not open a public issue.

* Email: **JasonLeoZhou@outlook.com**
* Or use GitHub's [private vulnerability reporting](https://github.com/JLeo0001/LeoSync/security/advisories/new)

Please include:

* the version of LeoSync you are running (About → App version),
* your Android version and device model,
* a clear description of the issue and, if possible, steps to reproduce it.

Please allow reasonable time for a response and a fix before disclosing the
issue publicly.

## Scope

LeoSync bundles a third-party sync engine. Issues in that engine itself
should be reported to the engine project instead.

Please **never** include credentials, OAuth tokens or `engine.conf` contents in
a report — redact them first.
